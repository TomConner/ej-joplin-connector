# Joplin MCP

- Prefer the Joplin MCP server for any task that reads or changes Joplin content.
- Use the smallest Joplin tool that answers the request.
- If the server is not registered yet, install it from the repo root before proceeding.
- Avoid inventing multi-step workflows when a single Joplin tool can do the job.
